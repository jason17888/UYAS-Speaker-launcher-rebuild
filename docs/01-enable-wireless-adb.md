# 步驟 0：在喇叭上開啟無線 adb

喇叭沒有 USB 孔，只能用無線 adb（TCP 5555）。原廠系統內建一個隱藏的 **Console** 工具可以開啟它。

## 做法

1. 喇叭開機後，進入 **藍牙模式**。
2. **同時按住喇叭上的 5 個實體按鍵**，螢幕上會出現 **虛擬導航列**（三個虛擬按鍵）。
3. 點 **中間那顆（Home）**，進入原廠桌面（Launcher3）。
4. 在桌面找到名為 **Console** 的應用程式並開啟。
5. 在 Console 內找到 **ADB Wireless**，點選開啟。

## 這份流程的依據

- 步驟 1 到 4 是作者在自己機器上的實際操作。
- 步驟 5：原廠 launcher 的反編譯碼裡，`ConsoleActivity` 確實有名為 `ADB Wireless` 的按鈕，
  同一份程式也有 `com.uyas.speaker.enable_wireless_adb` 廣播，接收後會把系統屬性
  `persist.internet.adb.enable` 設為 `1`。
- **按鈕和廣播之間的連結，我沒有逐行追到底**，所以不能保證點按鈕就是走這條路。
- 作者**沒有在一台全新的原廠機器上完整走過一遍**，按鍵位置與畫面可能和你的機器略有出入。

## 取得喇叭的 IP

- 看路由器的已連線裝置清單，找 `UYAS`。
- 作者機器的螢幕右下角有原廠診斷疊層（顯示 IP 等），但未確認每台都有。

## 連線測試

在 PC 上執行（位址換成喇叭的 IP）：

```powershell
adb connect 192.168.1.50:5555
adb devices
```

應看到 192.168.1.50:5555 後面接 device。電腦與喇叭必須在同一個區網。

## 常見問題

| 狀況 | 處理 |
|---|---|
| `connection refused` | 步驟 5 沒成功，或設定沒保留；再做一次 |
| 找不到 Console | 確認進到的是原廠桌面（Launcher3），而不是音樂 App |
| 5 個按鍵同時按沒反應 | 要在 UYAS 介面或藍牙頁面按，且要同時按住 |
| `unauthorized` | 作者機器沒有 adb 驗證；若出現，請看喇叭螢幕有無授權提示 |

作者機器上，persist.adb.tcp.port 重開機後仍保留（值為 5555）。
